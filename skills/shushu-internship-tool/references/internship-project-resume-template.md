# 实习项目简历参考模板

适用场景：用户已经整理好项目材料，希望把零散信息压缩成更像正式简历的项目经历。

## 推荐结构

```md
### [公司 / 团队名称] | [岗位名称]
[时间区间]

**[项目名 / 负责方向]**

项目背景：面向[业务对象/场景]，为了解决[核心问题]，搭建/优化了[系统/流程/平台]，带来[业务价值或工程价值]。

- [模块1标题]：负责[前置动作/系统搭建/关键设计]，覆盖[技术方案/关键机制]，支撑[后续能力或目标]。
- [模块2标题]：围绕[核心链路/关键问题]，完成[优化动作/规则设计/工程改造]，解决了[具体痛点]。
- [模块3标题]：沉淀[评估/监控/数据/归因]机制，能够支持[验证效果/问题定位/策略迭代]。
- [模块4标题，可选]：补充[安全/稳定性/fallback/协作机制]，降低[风险/误判/人工成本/系统不稳定性]。
```

## 填写规则

- 项目背景优先回答三个问题：这是做什么的、为什么要做、价值在哪里。
- bullet 顺序优先按因果展开：先写基础搭建，再写链路优化，最后写结果或收益。
- 只保留有价值的信息：优先写业务结果、工程收益、效率提升、稳定性改进、风险控制。
- 不要把“读了多少文件”“整理了多少文档”“看了多少 case”单独当成果，除非能明确说明带来了什么价值。
- 如果两个模块本质上属于同一条主线，可以合并成一条 bullet，但要保证主语统一、逻辑连贯。
- 如果没有硬指标，可以写“支撑了什么能力”“避免了什么问题”“让什么流程更稳定”，但不要硬编数字。

## 可直接套用版本

```md
### [公司名称] | [岗位名称]
[2024.06 - 2024.09]

**[项目名称] | [核心职责]**

项目背景：面向[用户/业务团队/内部流程]，为解决[效率低/人工成本高/结果不稳定/缺少可观测性]的问题，搭建并持续优化[Agent 工作台/评估链路/自动化系统]，支撑[业务提效/质量提升/风险控制]。

- [基础能力搭建]：设计并实现[平台/服务/核心链路]，补充[接口协议/数据结构/并发控制/任务恢复]等关键机制，为后续[调用编排/评估/分析]提供稳定基础。
- [核心链路优化]：围绕[检索/评估/归因/调度]链路，完成[规则优化/prompt 调整/流程拆分/数据过滤]，减少[无效调用/误判/人工干预]。
- [评估与可观测性]：沉淀[golden cases/指标看板/日志字段/追踪链路]，支持对[效果变化/问题来源/迭代收益]进行持续验证。
- [安全与稳定性]：补充[权限边界/人工确认/fallback/异常拦截]机制，降低[高风险操作/线上误用/不可逆执行]风险。
```

## 生成提示建议

当基于这个模板生成简历内容时，优先遵循以下约束：

- 先补全“项目背景”一句，再生成 3 到 4 条 bullet。
- 每条 bullet 只表达一个主点，不要把背景、动作、结果全部堆在一条里。
- 若存在明确因果关系，按“搭建/设计 -> 优化/迭代 -> 结果/收益”排序。
- 若材料中有多个强相关模块，可提供“拆开写”和“合并写”两个版本供用户选择。
- 若缺少明确价值，只保留为补充说明，不要提升为正式简历 bullet。
